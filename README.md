# FPGA Digital Design - NTI Bootcamp

This repository contains my digital design tasks and Verilog implementations created during the NTI (National Telecommunication Institute) summer bootcamp. 

The main goal of this repository is to document my progress in learning Hardware Description Languages (HDL) and digital logic design.

## 📂 Repository Contents

*   **[Full Adder by using different types](./Full%20Adder%20by%20using%20different%20types):** Implementation of a Full Adder using Behavioral, Dataflow, Gate-Level, and Structural modeling.
*   **[MUX(4x1) by using different types](./MUX(4x1)%20by%20using%20different%20types):** Design of a 4-to-1 Multiplexer using the four different Verilog modeling styles.
